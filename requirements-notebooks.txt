# Packages needed to run the workshop notebooks OUTSIDE Google Colab.
#
# The workshop is designed to run in Colab, where most of these are already
# installed. This file is a convenience for anyone who cannot use Colab.
# It is NOT used by any workflow; the site build uses requirements.txt.
#
# Two things will still not work locally, and the affected cells must be skipped:
#   1. `from google.colab import drive` / `drive.mount(...)` and
#      `from google.colab import userdata` — these exist only inside Colab.
#      Point ROOT at your own copy of the STI_2026 folder instead of
#      /content/drive/MyDrive/STI_2026.
#   2. `import pw_nowcasting_functions` — this helper module ships inside the
#      STI_2026 folder, not on PyPI. Keep it next to the notebook.
#
# Tested target: Python 3.11 (the version Colab runs). Versions are left
# unpinned to match how the notebooks install them; pin them if you need a
# reproducible environment.
